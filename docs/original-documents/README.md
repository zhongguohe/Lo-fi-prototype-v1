Three original DOCX files were supplied by the user earlier in this project. They were not in the project root when maintenance began, but still existed at the previously provided Downloads paths. On 2026-11-07 they were copied here unchanged, retaining their filenames. Originals remain at their original locations. Byte counts and SHA-256 hashes are recorded in `source-manifest.json`.

- `SI684 Lo-fi v1｜信息架构与用户流程（中文版） (2).docx`: source information architecture, flows, page/state/dialog inventory, Personal Center rules, classroom-task guidance.
- `Design project problem statement.docx`: problem, target population, two behaviors, proposed components, and evaluation framing.
- `draft_SI684_Causal_Diagrams.docx`: causal hypotheses, draft notes, references, and future questions; not proof of effectiveness or blanket authority to implement every suggestion.

`extracts/` preserves the previously read paragraph-text Markdown conversions. The originals retain embedded diagrams and document metadata; the extracts are not a faithful visual render. The maintainer read the text sources, not an independent new analysis of the embedded diagram images. The top-level `docs/problem-statement.md` and `docs/causal-diagrams.md` remain unchanged for compatibility.

The current implementation's [IA](../information-architecture.md), [flows](../user-flows.md), and [decisions](../design-decisions.md) record scope overrides and differences. No missing originals are claimed: all three named files were found and copied. No participant dataset, raw interview notes, or completed walkthrough video was supplied for this archive.

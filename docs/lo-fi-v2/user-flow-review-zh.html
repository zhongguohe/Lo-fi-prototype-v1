V1参考｜协作背景与分工

本次工作基于共同仓库中已有的 v1 原型，在 Valen_branch 上完成 lo-fi v2 作业的修改。分支提交后，组员检查更新内容并进行用户任务走查，再按小组约定合并。

代码审查由负责的组员及其 agent 完成。用户任务走查主要检查流程是否连贯、操作结果是否符合预期，以及活动记录和进度是否一致。组员优先检查本次修改涉及的任务，并完整体验一次学习休息和计划运动流程；61项详细检查作为进一步排查的参考。

下方流程图记录修改前的 v1；任务表列出预期结果，其中部分仍对应已知问题。v2实施后，更新说明将列出实际改动和重点复查任务。

V1参考｜主要走查任务

获取 Valen_branch 的最新代码并启动本地网页，确认当前分支和提交版本。走查可使用示例数据或自建测试记录；重置前确认本地数据可以清除。环境准备可交由各自的 agent 完成。

用户任务操作步骤预期结果
1. 完成首次设置设置学习和运动偏好，选择是否显示宠物，点击 Save & Continue进入首页；再次打开时保留设置
2. 完成学习休息首页 → Study → Start Studying；展开 Prototype time controls → Simulate Next Reminder → Start Break → Start Activity → Finish Activity → Save Activity提醒、活动和确认页面衔接正常；保存后才计入休息记录
3. 延后休息提醒提醒出现时选择 Remind Later，再选5或10分钟返回学习页并显示新的提醒时间；延后操作不计为活动
4. 暂停与恢复分别操作 Pause Study／Resume Study 和 Pause Reminders／Resume Reminders暂停学习会停止学习计时；仅暂停提醒时学习计时继续
5. 创建运动计划Exercise → Create Exercise Plan → 填写活动和时间 → Next → 填写备用活动 → Save Plan计划保存并显示在列表中；创建计划不增加运动分钟
6. 返回修改备用方案填写备用活动后返回上一步，再点击 Next；分别检查顶部和页面内的 Back两种返回方式均保留已输入内容
7. 调整受阻的运动计划计划详情 → I Can't Do This Now；分别操作 Use Backup、Reschedule，以及取消或确认 Skip备用活动可以执行；改期更新计划时间；跳过不扣除历史进度，也不计为完成
8. 连续完成不同活动保存活动 → View Progress → 进入另一项运动并开始正常进入新活动，不返回上一条活动的保存页面
9. 更正活动记录Progress → View Activity History → 记录 → Edit → 修改时长 → Save；另检查取消编辑统计按更正后的记录更新，无重复计分；取消保留原记录
10. 检查日期限制补录实际活动时选择未来日期；运动改期时选择过去时间未来活动不计为已完成；过去的计划时间有明确提示或限制
11. 查看进度与切换宠物查看两类活动的进度；在宠物页关闭后重新开启两类活动分别统计，数字含义明确；宠物开关不影响记录和累计进度
12. 调整目标与检查导航调整周目标，检查其生效时间；检查页面返回、取消与切换目标按所选时间生效；操作无阻断、意外输入丢失或结果不一致

走查范围以本次修改为主，并保留两条核心流程的完整检查。可使用模拟时间控件缩短等待；模拟操作仅用于检查原型交互，不作为真实活动完成的证据。
